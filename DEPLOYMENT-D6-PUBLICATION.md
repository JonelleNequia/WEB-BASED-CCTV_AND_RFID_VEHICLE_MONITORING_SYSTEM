# PHILCST VMS — D6 Offline Testing Packages

**PRE-RELEASE / testing candidates, not certified production installers.**
Packages operate offline after the complete download/USB transfer. Windows is a
complete x64 ZIP; no Setup EXE exists for this candidate. Mac packages use
`Install.command`. Apple Silicon's dependency minimum is macOS15; Intel's is14.
Actual minimum-OS/native installed acceptance is pending. Arm64 packaged runtime
fixtures passed on macOS26.6.1; Windows/Intel execution is NOT RUN.

Packages are unsigned; Mac code signatures are ad-hoc, with no Developer ID or
notarization. Native installation/reboot/browser trust/hardware/load acceptance and
maintenance gates remain. Production update/transfer compatibility remains
restricted and no stable update index is enabled. Additional PCs acting as browser
clients need only the matching client helper and a browser, not another server.

  D5D-capable controller capsule, protected ownership, installed compatibility
  status and readiness-gated resume. Existing operational DBs/legacy adoption are
  refused; completed or unknown missing state is never reinitialized.
- Missing publisher trust is a visible disabled feature. Check/download defaults
  remain off and no automatic install/worker or fixture root is introduced.
  Transfer authority is independently enrolled and preserves the D6 initial owner.
- Exact source/version/build re-entry verifies without copying files, reseeding,
  migration or setup-code issuance. Stop/Start use the owned maintenance workflow;
  retired owners and incomplete recovery remain refused.
- Ordinary D5B/D5C identity checks remain strict. D5D alone authenticates a precise
  transitional target capsule binding when deployment identity changes, and then
  rebinds the existing unchanged local controller receipt. Wrong signatures/targets
  or absent promotion intent cannot authorize that transition. No incoming helper
  or source executable replaces target authority.
- Packaged installers no longer create the public/storage symlink that conflicts
  with immutable-code checks. Authenticated historical media routes remain the
  serving path. Protected Mac lifecycle/controller/recovery/transfer/update/setup
  islands are excluded from broad mutable-state permission traversal.
- Inno now checks uninstall eligibility before removing registered files/shortcuts.
  Managed uninstall remains blocked pending native removal/retention acceptance;
  no destructive legacy uninstall is advertised as supported.
- Runtime extraction caches bind exact input pins, not only architecture names.
  Loose generated bytecode is excluded; Windows pip uses no-compile. Source capture
  refuses HEAD changes during capture. Operator links are rendered for the actual
  package layout rather than shipping broken development paths.
- A combined integration run exposed a build/runtime `contract` module-name
  collision. The delivery-review tool now loads its exact build validation module
  by path; an explicit shadowing regression passes. Runtime controllers and their
  trust contracts are unchanged.
- Manual workflows retain read-only permissions/manual dispatch, use verified full
  action commits, build client helpers with the common source/version/build identity,
  and preserve partial-matrix failure evidence. Inno build tool is version/hash/publisher
  pinned. No workflow was triggered remotely.

production Composer preparation. The frozen build lacked leading-5/-ml-px/rounded-l-md
utilities present when vendor templates existed. Both builders now prepare the

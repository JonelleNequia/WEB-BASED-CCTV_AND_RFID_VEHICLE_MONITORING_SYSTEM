# D3 native acceptance record — run per artifact/architecture

Use disposable isolated Macs/VMs, never the working school's installation. Record
archive SHA-256, source SHA, common build identity, OS build and native CPU.
A runtime probe on a development Mac is not clean offline installation acceptance.

1. Verify trusted checksums and signatures independently. Disconnect WAN, remove
   development tools from PATH and verify no separately installed PHP/Python,
   Composer, Homebrew, Git or npm is required. Test minimum dependency OS and
   current OS separately on native Intel and Apple Silicon (no Rosetta).
2. Extract to a folder with spaces. Run Install.command in the isolated target.
   Confirm preflight before data/services mutation, root-owned release files,
   protected separate shared state and hidden non-login service account.
3. Run packaged readiness --inference. Confirm PHP extensions/SQLite/Argon2id,
   all native imports, YOLO/EasyOCR/ONNX, two-frame ByteTrack stable IDs and CPU
   execution. No online dependency/model or font download may occur.
4. Deliver root-only first-admin code privately, set a personal password, sign in,
   delete delivery file. Create synthetic tagged/untagged vehicles and historical
   media. Verify printed tag numbers, lost UID rules and exact literal plates.
5. Feed a recorded H264 video through the real detector path (no physical camera).
   Use synthetic keyed POST /api/v1/integration/rfid-scans with tag_uid,
   scan_location and reader_name. Confirm existing occurrence/idempotency rules.
   Keep physical-camera/reader results separate, including local-network privacy,
   any USB/webcam TCC restrictions and vendor drivers. No broad sudoers workaround.
6. Missing/corrupt model or dylib must fail hash/readiness with no download. Occupy
   each TCP/UDP port; test wrong-architecture/old-OS, unowned launchd job/account,
   another collector, low disk, network SQLite path, symlink redirects, missing
   keys/DB and legacy/different-source root. Refuse without killing unrelated work.
7. Same-source reinstall: account login, APP_KEY/API key, DB IDs, images,
   calibration, reader/camera assignments, denylist and completed provisioning
   must survive. Inject copy/native/provisioning failure; report partial state
   clearly. D5 recovery/rollback is pending; do not reset or generate new keys.
8. Reboot without browser open. Confirm six owned LaunchDaemons, throttling,
   scheduler interval, bounded child logs, working dirs/identities and local app
   health; distinguish camera/reader readiness. Test locked/logged-out privacy.
9. Check Gatekeeper/quarantine offline on transferred package, Developer ID and
   stapled notarization when available. Ad-hoc signatures do not authenticate a
   publisher. Do not disable global Gatekeeper to make acceptance appear green.
10. D4 named HTTPS/LAN and D5 maintenance/backup/update/restore/transfer remain
    release gates. Do not advertise those from a successful D3 runtime check.
